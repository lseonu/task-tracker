# Anti-Patterns

Use these as draft anti-patterns for the MVP. Replace or refine them with sponsor-approved guidance before launch.

## Avoid These Project Shapes

- Thin wrapper: a single prompt in a shallow UI with no meaningful workflow
- Generic chatbot: broad assistant behavior with no defined user or task loop
- Baseline file or website Q&A: simple retrieval presented as a full application
- Demo with no product loop: a flashy screen or video but no credible end-to-end use
- Unsupported claims: claiming advanced capabilities that the current build cannot actually demonstrate
