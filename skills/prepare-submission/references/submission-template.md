# Submission Template

Create or update `devpost-submission.md` in the project root with these sections.

## Required Draft Sections

- `# Title`
- `## One-line Summary`
- `## Problem`
- `## Solution`
- `## Why This Matters`
- `## How We Used OpenAI`
- `## How We Used Codex`
- `## Key Features`
- `## Architecture`
- `## Testing Instructions`
- `## Public Demo Link`
- `## Public Repository Link`
- `## Demo Video`
- `## Screenshot Shot List`
- `## Known Limitations`
- `## TODO Official Form Fields`

## Writing Notes

- Keep claims specific and testable
- Make the OpenAI and Codex usage concrete
- Label placeholders clearly when the real event form is still unknown
