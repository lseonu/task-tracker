# Preflight Checklist

Use this checklist before the user leaves Codex to submit on Devpost.

## Core Readiness

- Rules review acknowledged
- Project concept recorded in state
- Build is real enough to describe honestly
- Submission draft file exists

## Submission Materials

- Clear title
- Concise summary
- Problem and solution described
- OpenAI usage explained
- Codex usage explained
- Testing instructions included
- Public repo link present or explicitly marked TODO
- Public demo link present or explicitly marked TODO
- Demo video plan or URL present or explicitly marked TODO
- Screenshot shot list present

## Compliance

- Draft does not hide unresolved placeholders
- Build claims do not overstate what the project does
- Obvious anti-pattern issues have been addressed or acknowledged
