# Demo Script

## 0:00 - Problem

Developer work is scattered across GitHub issues, PR reviews, GitLab issues, Linear items, and undocumented housekeeping. Task Tracker focuses on deciding what should happen next.

## 0:15 - Queue

Open the app at `http://127.0.0.1:4173/` and show the seeded queue. Point out that the queue is the main surface and the `Next Up` panel is always visible.

## 0:35 - Manual Capture

Add a manual housekeeping task named `Renew Tiny Tools submission checklist`. Explain that not every real task lives in an issue tracker.

## 0:55 - Triage

Filter to housekeeping and sort by priority. Show that scattered work can be narrowed into a useful slice quickly.

## 1:15 - Next Up

Show the ranked top 3. Explain that the first recommendation wins because it prioritizes unblocking others, then recent momentum, then deadline/risk.

## 1:45 - Bot Candidates

Switch to the Bot Candidates view. Explain that these are small, well-scoped jobs that a coding agent could attempt later.

## 2:05 - Completion

Mark the manual task done and show the undo toast. Explain that the queue and recommendation update immediately.

## 2:25 - Close

Summarize the product: Task Tracker is not just another todo list; it is a personal developer triage cockpit for deciding what to do next.
