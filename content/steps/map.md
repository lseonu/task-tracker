# Find your place

This recovery page shows where you are in the OpenAI Codex Hackathon flow and which command should come next.

Use `$hackathon-map` any time you lose track, switch chats, or want to confirm whether the optional learning path is active.

The five required steps are Start, Rules, Resources, Prepare, and Check. The optional learning path stays nested inside Resources and returns to Prepare when the build is ready for submission work.

Codex does not submit to Devpost automatically. The final handoff still happens in the browser.
