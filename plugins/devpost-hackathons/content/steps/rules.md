# Review the rules

Confirm the requirements before you start building.

Read the current eligibility, deadlines, deliverables, judging notes, and official disclaimers before you answer in chat. The confirmation is intentionally simple: reply `yes` only when you understand the rules well enough to continue.

If anything is unclear, ask Codex questions before replying. Codex can help interpret the current rule text, but the official Devpost page remains the source of truth for final eligibility and submission requirements.
