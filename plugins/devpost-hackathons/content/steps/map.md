# Find your place

This recovery response shows where you are in the OpenAI Codex Hackathon flow and which command should come next.

Use `$hackathon-map` any time you lose track, switch chats, or want to confirm whether the optional guided build tool is active.

Not sure which hackathon you are in yet? Start with `$find-hackathon` to browse and pick one, or `$start-hackathon` if you already know which one you want.

The five required steps are Start, Rules, Resources, Prepare, and Check. The optional guided build tool stays nested inside Resources and returns to Prepare when the build is ready for submission work.

Codex does not submit to Devpost automatically. The final handoff still happens in the browser.
