# Choose your build path

Use the resources, or start the optional guided learning path.

You have two good paths from here.

If you already know what you want to build, keep moving toward submission prep with `$prepare-submission`. Codex will help turn your project into a Devpost-ready story, identify missing materials, and prepare you for final review.

If you want more structure, start the optional learning path with `$learning-onboard`. It stays inside Step 3 and gives you a guided sequence: Ideate, Scope, PRD, Spec, Checklist, Build, then Return. Codex will interview you, write planning documents in your project, and use those documents as build context.

The guided path is optional. It is best for participants who want to practice a more durable AI-assisted development workflow while still building something they care about.

Codex Desktop can also preview local web apps as you build. Later in the flow, when your project has something visual to inspect, you can ask Codex to open the local dev server in the in-app browser so you can review your own app alongside this hackathon guidance.

Before launch, the event owner can add final resource links, kickoff videos, examples, and sponsor-specific notes here.
