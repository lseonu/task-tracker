# Run your final check

Review completeness, security, and handoff readiness.

Codex will summarize whether you are ready, close, or not ready to leave Codex and complete the official submission in Devpost.

This step includes the local security scan result, with redacted findings only.

If the result is ready, you are done in Codex. Your last task is to submit on Devpost:

- Open the official Devpost submission page.
- Copy the final material from `devpost-submission.md`.
- Add the repository link, demo link, screenshots, and demo video.
- Submit the official form before the deadline.

If the result is close or not ready, fix the listed blockers first and run `$submission-check` again.
