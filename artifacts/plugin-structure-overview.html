State Model

Small by design

The state file is the continuity layer. Skills read and update it, then re-render the map so the participant always knows where they are.

current_stage Current command stage shown in the map.
completed_stages Progress markers for the required flow.
rules_acknowledged Legal/fairness gate. Now only `yes` unlocks.
registration Currently browser handoff; future Devpost MCP can sync it.
project Name, summary, OpenAI usage, Codex usage.
submission Draft file, URLs, status, and handoff readiness.
